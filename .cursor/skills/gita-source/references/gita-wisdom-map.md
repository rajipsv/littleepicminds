## Per-concept chain

```text
Concept
  → Gita chapter(s)
  → Verse anchor(s)
  → child-friendly one-liner (registry coreIdea / theme)
  → gv{book}_a{adv} module
  → activity + reflection (gita-learning)
```

## Example: Results / effort

```text
Concept: Results (non-attachment to fruits)
Chapter: 2 · Karma Yoga themes in 3

Child line: "Do your best. You can't control everything that happens next."
Registry: Book 3 modules (Mira lead) · also Book 2 steadiness themes
Experiences: competition, performance, trying hard, waiting for marks
```

## Using this map

1. **`gita-source`** — given verse, tag concept(s) in VERSE RECORD
2. **`gita-story`** — pick child experience from concept's experience list
3. **`gita-grove-world`** — match lead blind spot to concept (e.g. Mira + rushing + effort)
4. **`gita-quality`** — verify concept not overused in same book arc

Full per-module mapping: `docs/gita-grove/master-architecture.md` + `module-registry.json`.
