# Quality checklist

## Gita accuracy

- [ ] Story embodies `coreTeaching` of anchor verse(s)
- [ ] No distortion for simplicity
- [ ] Remember ślokas synced (`verified-repo` or `verified-mcp`)
- [ ] No hand-crafted Sanskrit/transliteration
- [ ] rememberLine book voice · ties to felt experience
- [ ] Story body has no Arjuna/Krishna lecture

## Story quality

- [ ] Opening hook — not "today we learn…"
- [ ] Lead wants something concrete
- [ ] Blind spot causes mistake
- [ ] Consequence is real
- [ ] Transformation shown in action
- [ ] Enjoyable with zero Gita knowledge
- [ ] Supporting character did not deliver the moral

## Age 5–10

- [ ] 40–60 words per story spread
- [ ] Vocabulary accessible across band
- [ ] Not preachy · not babyish
- [ ] Practice doable for 5–10 without age split

## Character

- [ ] Lead + supporting match registry
- [ ] Distinct speech styles (Thinker/Doer/Feeler/etc.)
- [ ] Only two children on stage (usual)
- [ ] Vanshi ≠ Vihaan roles respected

## World continuity

- [ ] Location from world bible
- [ ] No talking animals / divine rescue in story body
- [ ] No Guru Ma · no v1 animal cast
- [ ] Page 25 teaser matches next module hook

## Learning

- [ ] Moral tied to theme
- [ ] 3 Practice activities · theme-linked
- [ ] Celebrate names what lead practiced
- [ ] Grown-up page 80–120 words

## Series

- [ ] Concept not duplicate of sibling module in same book
- [ ] Continuity notes in series-bible updated
- [ ] curriculum.json status + paths correct

## Ship gate

**SHIP** only if all dimensions PASS or WARNING with documented accept.

**REVISE** if any FAIL.
