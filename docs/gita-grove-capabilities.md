# Gita Grove — Capability Map

**Version:** 1.0 (design)  
**Status:** Authoritative for Grove v2 series  
**Audience:** Authors, illustrators, parents (internal)

---

## Purpose

This document defines the **18 Grove Powers** — trainable inner capabilities that structure the entire Gita Grove series. Each print book (~80–100 pages @ ~₹199) grows **one power** through multiple adventure modules (~25 pages internal each).

**Design order for every adventure:**

1. Grove Power → 2. Sub-skill → 3. Training location → 4. Character flaw → 5. Scenario → 6. Story (organic) → 7. Ślokas paired **last** (Remember section only)

**Rejected as design drivers:** pandit blocks, verse-shaped titles, Mahabharata cosplay in Seeds text, plots that exist because “śloka X means Y.”

## Five arcs & Tree of Wisdom

Each arc adds a **branch color** on the Tree of Wisdom. Each completed adventure = **one leaf** on that book’s branch.

| Arc | Books | Kid-facing arc name | Branch color (design) | Powers in arc |
|-----|-------|---------------------|----------------------|---------------|
| **I** | 1–2 | When life feels too big | Soft gold | Honest Heart, Steady Me |
| **II** | 3–6 | How we show up | Leaf green | Helpful Hands, Learning Heart, Calm Inside, Gentle Focus |
| **III** | 7–11 | How we see the world | Sky blue | Wonder Eyes, Remember Light, Safe Belonging, Spark Finder, Wide Wonder |
| **IV** | 12–15 | Who we are inside | Blossom pink | Kind Friend, Inner Gardener, Mood Weather, Deep Roots |
| **V** | 16–18 | How we live forward | Deep bark brown | Brave Choices, Good Habits, My True Path |

**Finale (Book 18):** All six friends + Guru Ma Owl under the full Tree.

## Seeds vs Seekers (by power)

| Grove Power | Seeds (5–7) — child can say/do | Seekers (8–10) — deeper layer |
|-------------|----------------------------------|-------------------------------|
| Honest Heart | “My tummy feels funny.” / “I need help.” | Duty vs fear; loyalty vs fairness (school/home) |
| Steady Me | Lose game; try again tomorrow | Not defined by one result; effort vs outcome (felt, not quoted) |
| Helpful Hands | Share, carry, fix together | Lead by serving; don’t copy someone else’s job |
| Learning Heart | Ask Owl; enjoy helping after learning | Humility before teachers; knowledge makes work light |
| Calm Inside | Rainy day; still okay inside | Busy but peaceful; not cold or uncaring |
| Gentle Focus | One task; come back when distracted | Study, sport, friendship — same skill |
| Wonder Eyes | “Everything connects!” | Many ways to seek good; sincere > loud |
| Remember Light | Think of home when path is dark | What we hold in heart when scared |
| Safe Belonging | “They didn’t forget me.” | Trust when small; sincere gift |
| Spark Finder | Best leaf, best ant — no ranking friends | Excellence everywhere; wonder not competition |
| Wide Wonder | Night sky; gentle awe | Time changes things; love after overwhelm |
| Kind Friend | Include, forgive, mend | Equal to friend and stranger; peaceful heart |
| Inner Gardener | “I tend my thoughts like plants.” | Body/mind habits; humility |
| Mood Weather | Red / yellow / blue day | Moods pass; don’t be slave to one color |
| Deep Roots | “What matters under the rush?” | Purpose beneath wanting and showing off |
| Brave Choices | Pick kindness over grab | Hero habits vs anger, greed, show-off |
| Good Habits | Nice words, shared snack | Food, speech, gifts shape mood |
| My True Path | “This is my part in the play.” | Own talent; trust; series homecoming |

## End-of-adventure template (every module)

| Step | Content |
|------|---------|
| **Celebrate** | Name the Grove Power: “Mimi grew **Honest Heart** today.” |
| **Practice** | Activity tied to sub-skill |
| **Listen** | 2 ślokas (paired after story draft); audio QR |
| **Owl line** | One short paragraph per adventure — opens *In the Bhagavad Gita, from India's puranas* (or *one of India's great puranas*); reflects the **meaning** of the paired ślokas; story body stays name-free; grown-up page may name Dhritarashtra, Arjuna, etc. |
| **Repeat** | One child line |
| **Grown-up** | Power name + discussion question + verse refs (optional depth) |

**Never in story body:** “This story was about śloka…”

## Authoring checklist (per adventure)

- [ ] Sub-skill identified from this doc  
- [ ] Location matches training ground  
- [ ] Lead character’s flaw creates natural conflict  
- [ ] Title = moment/object (not verse vocabulary)  
- [ ] Story works with zero Gita knowledge  
- [ ] Seeds: no Dhritarashtra, Kurukshetra, verse lectures  
- [ ] Ślokas chosen **after** draft from correct chapter pool  
- [ ] Remember names **power**, not śloka
